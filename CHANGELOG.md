# Changelog

## 0.1.0-dev

Current stabilization preview:

- routing, middleware, HEAD/OPTIONS and 405 handling
- request/response helpers and malformed-JSON handling
- plain PHP views
- PDO query builder with NULL/IN/value/pluck/exists helpers
- lightweight models with explicit mass-assignment fields
- validation including database and upload rules
- safe upload helper
- hardened sessions and CSRF rotation
- simple database authentication without password-hash exposure
- migrations compatible with MySQL/MariaDB DDL behavior
- CLI generators, route listing and environment doctor
- Composer and Composer-free autoloading
- Apache shared-hosting fallback
- platform-independent PHP linting
- CI on PHP 8.3, 8.4, 8.5, SQLite and MariaDB 11
- repository issue and pull-request templates

A stable 0.1.0 release still requires the real-hosting verification checklist to pass.
