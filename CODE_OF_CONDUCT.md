# Code of Conduct

SedoPHP aims to keep collaboration technical, respectful and productive.

## Expected behavior

- Discuss code and ideas, not people.
- Give actionable technical feedback.
- Assume good intent, but be clear about bugs, risks and trade-offs.
- Respect different experience levels, backgrounds and viewpoints.
- Keep issues and pull requests relevant to the project.
- Do not publish private information, credentials or security-sensitive details.

## Unacceptable behavior

Harassment, threats, discriminatory language, personal attacks, spam, deliberate disruption and disclosure of another person's private information are not acceptable.

## Security reports

Security vulnerabilities must not be posted publicly. Follow [SECURITY.md](SECURITY.md) and use GitHub's private security-advisory process.

## Enforcement

Project maintainers may edit, hide, lock or remove content and may restrict participation when necessary to keep the project safe and productive.

Questions about conduct can be raised privately with the project maintainer through the contact information on the maintainer's GitHub profile.
